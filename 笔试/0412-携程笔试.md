## 2

### 题目描述

有一条由 $n$ 个灯珠组成的灯带，每个灯珠仅有两种状态 $0$ 或 $1$。灯带上相邻的灯珠之间的焊点具有权重 $w_i$（对应第 $i$ 个灯珠与第 $i+1$ 个灯珠之间的焊点）。定义灯带的相融度为所有相邻灯珠状态相同的焊点权重之和。

你可以进行至多一次翻转操作：选择一个连续段 $[l, r]$（$1 \leq l \leq r \leq n$），将该区间的每个灯珠状态 $0$ 与 $1$ 互换（$0 \leftrightarrow 1$）。也可以不进行任何操作。请计算操作后灯带的相融度的最大值。

名词解释

- **相邻对**：指灯珠 $i$ 与灯珠 $i+1$ 组成的有序对（$1 \leq i \leq n-1$）。
- **焊点权重**：指相邻对 $(i, i+1)$ 之间的权重 $w_i$，用于统计相融度。
- **相融度**：所有满足灯珠 $i$ 与 $i+1$ 状态相同的相邻对的权重之和，即
  $\sum_{i=1}^{n-1} w_i \cdot [s_i = s_{i+1}]$
  其中 $[ \ ]$ 为指示函数。
  
- **连续段**：数组的一个闭区间子段 $[l, r]$，包含位置 $l, l+1, \ldots, r$。
- **翻转操作**：将选定连续段内每个灯珠状态 $0$ 与 $1$ 互换。

### 输入描述

第一行输入整数 $n$（$2 \leq n \leq 10^5$），表示灯珠数量。

第二行输入一个长度为 $n$ 的二进制字符串 $s$（字符仅为 $\text{'0'}$ 或 $\text{'1'}$），第 $i$ 个字符表示第 $i$ 个灯珠的初始状态。

第三行输入 $n-1$ 个整数 $w_1, w_2, \ldots, w_{n-1}$（$1 \leq w_i \leq 10^9$），表示各相邻对之间的焊点权重。

### 输出描述

输出一个整数，表示操作后灯带的相融度的最大值。

### 示例

输入

```
5
01010
2 1 3 4
```

输出

```
7
```

### 题目描述

在一维直线上给定 $n$ 个人的初始位置 $x_1, x_2, \dots, x_n$（单位米），保证这些位置两两不同。给定一个长度为 $n$ 的 $01$ 字符串 $s$ 表示每个人的运动方向：

$s_i = 0$ 表示第 $i$ 个人向左移动，$s_i = 1$ 表示向右移动。所有人的速度均为 $1$ 米/秒。给定一个非负整数 $k$（单位秒），人群运动互不影响，视为两点在相同位置时即视为相遇，相遇后仍保持原来的运动方向和速度，不发生反弹或其它相互作用。请输出在 $[0, k]$ 内发生相遇的不同人对应的数量。如果两个人在某个时刻 $t \in [0, k]$ 到达了同一位置，则称他们在此时间区间内发生了一次相遇。

### 输入描述

每个测试文件包含多组测试数据。第一行输入一个整数 $T$（$1 \leq T \leq 10^5$）表示数据组数。接下来每组数据描述如下：

- 第一行输入两个整数 $n, k$（$1 \leq n \leq 2 \times 10^5$，$0 \leq k \leq 10^9$）。
- 第二行输入 $n$ 个两两不同的整数 $x_1, x_2, \dots, x_n$（$|x_i| \leq 10^9$），表示初始位置。保证这些位置两两不同。
- 第三行输入一个长度为 $n$ 的 $01$ 字符串 $s$，$s_i \in \{0, 1\}$。

保证所有测试数据 $n$ 的和不超过 $5 \times 10^5$。

### 输出描述

对于每组测试数据，输出一行一个整数，表示在 $[0, k]$ 内发生相遇的人对数。

---

### 示例

输入

```plaintext
3
4 3
0 2 6 9
1001
5 2
-2 -1 0 1 2
01010
2 1
5 7
10
```

输出

```
2
3
1
```





### 实现

```java
import sys

class Solution:
    def count_meet(self, n: int, k: int, x: list[int], s: str) -> int:
        people = sorted(zip(x, s))
        R = []
        L = []
        for pos, dir in people:
            if dir == '1':
                R.append(pos)
            else:
                L.append(pos)
        
        res = 0
        max_diff = 2 * k
        len_L = len(L)
        j = 0  # 右边界指针
        
        # 单指针遍历，仅维护右边界，left由r的升序保证
        for r in R:
            # 跳过<=r的元素
            while j < len_L and L[j] <= r:
                j += 1
            # 找到<=r+max_diff的最远位置
            while j < len_L and L[j] <= r + max_diff:
                res += 1
                j += 1
            # 回退j，保证下一个r能复用
            j -= 1
        
        return res

if __name__ == "__main__":
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    sol = Solution()
    for _ in range(T):
        n = int(input[ptr])
        k = int(input[ptr+1])
        ptr +=2
        x = list(map(int, input[ptr:ptr+n]))
        ptr +=n
        s = input[ptr]
        ptr +=1
        print(sol.count_meet(n, k, x, s))
```

### 题目描述

给定一个初始值为 $n$ 的数字。

每一秒，当前所有的数字都会同时执行分裂操作：

- 记分裂的数字为 $x$，它会分裂成两个数字：$\lfloor x/2 \rfloor + 1$ 和 $\lceil x/2 \rceil + 1$；
  此外，如果 $x$ 为奇数，它还会额外分裂出一个数字 $2$。

- 操作结束后，原数字 $x$ 被移除，仅保留新生成的数字，且所有数字的分裂基于该秒开始时的集合同时进行，不受其它分裂顺序影响。

求经过 $m$ 秒后，所有数字的总和。由于答案可能很大，请将结果对 $(10^9 + 7)$ 取模后输出。

### 输入描述

每个测试文件均包含多组测试数据。第一行输入一个整数 $T$（$1 \leq T \leq 10^4$）代表数据组数，每组测试数据描述如下：

- 在一行上输入两个整数 $n, m$（$1 \leq n, m \leq 10^9$）。

### 输出描述

对于每组测试数据，输出一行一个整数，表示经过 $m$ 秒后所有数字的总和模 $(10^9 + 7)$ 的结果。

### 实现

```java
import sys
MOD = 10**9 + 7

class Solution:
    def solve(self, n: int, m: int) -> int:
        if m == 0:
            return n % MOD
        
        # 模拟前30步，收敛到只有1和2
        cnt = {n: 1}
        for _ in range(min(m, 30)):
            new_cnt = {}
            for x, num in cnt.items():
                val = x // 2 + 1
                new_cnt[val] = new_cnt.get(val, 0) + num * 2
                if x % 2 == 1:
                    new_cnt[2] = new_cnt.get(2, 0) + num
            cnt = new_cnt
            m -= 1
            if m == 0:
                return sum(x * num for x, num in cnt.items()) % MOD
        
        # 提取1和2的数量
        a = cnt.get(1, 0) % MOD
        b = cnt.get(2, 0) % MOD
        
        # 递推计算剩余m步：a'=2a, b'=a+2b
        pow2 = pow(2, m, MOD)
        # 推导得：a(m) = a0 * 2^m, b(m) = (a0 * m + b0) * 2^m
        a_m = a * pow2 % MOD
        b_m = (a * m % MOD * pow2 % MOD + b * pow2) % MOD
        
        # 总和 = a_m * 1 + b_m * 2
        total = (a_m + 2 * b_m) % MOD
        return total

if __name__ == "__main__":
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    sol = Solution()
    for _ in range(T):
        n = int(input[ptr])
        m = int(input[ptr + 1])
        ptr += 2
        print(sol.solve(n, m))
```
