## 赛道赛车问题

### 题目描述

多多是一名赛车手，今天他来到一个特殊的赛车场。这个赛车场有 $n$ 条平行的赛道，每条赛道的长度都是 $m$ 米。赛道由两种路面组成：水泥地和泥地。

水泥地共有 $m$ 段，其中第 $i$ 段水泥地位于距离起点 $i-1$ 米的位置，覆盖了从第 $l_i$ 条到第 $r_i$ 条赛道（包括两端），长度为 $1$ 米。

多多驾驶赛车时：

- 在水泥地上的速度为 $1$ 米/秒
- 在泥地上的速度为 $0.5$ 米/秒

多多可以选取任何一条赛道出发，出发之后不允许变道。它现在想知道最快多少时间到达终点，如果有多条赛道满足最快的时间，他希望选取一条编号最小的。

### 输入描述

第一行包含两个数字 $n, m$（$1 \leq n, m \leq 10^5$）。

接下来 $m$ 行，每行包含两个数字 $l_i, r_i$（$1 \leq l_i < r_i \leq n$），表示第 $i$ 段水泥地覆盖的赛道。

### 输出描述

输出一行，包含两个数字，表示到达终点的最快时间和选取的赛道编号。

### 示例

输入

```
3 2
1 2
2 3
```

输出

```


```



### 思路

有 **n 条赛道（竖着排）**，有 **m 个位置（从起点到终点，一共 m 米）**。

整个场地其实是一个 **n × m 的网格**：

- 横轴：距离（0 → m）
- 纵轴：赛道编号（1 → n）

$\text{time}_j = (\text{水泥段数量}) \times 1 + (\text{泥地段数量}) \times 2$

$\text{time}_j = m + (\text{泥地段数量})$



### 实现

```python
class Solution:
    def solve(self, n, m, intervals):
        diff = [0] * (n + 2)
        for l, r in intervals:
            diff[l] += 1
            diff[r + 1] -= 1
        
        max_cnt = -1
        min_idx = 1
        current = 0
        for i in range(1, n + 1):
            current += diff[i]
            if current > max_cnt:
                max_cnt = current
                min_idx = i
        
        min_time = 2 * m - max_cnt
        return min_time, min_idx
```



## 辉夜盛典站位问题

### 题目描述

充满梦想与希望的虚拟空间“月读”即将举办一场名为“辉夜盛典”的演出，舞台导演多多正在为终幕的虚拟偶像大集合节目安排站位，共有 $N$ 位虚拟偶像参与该节目，舞台上共设有 $K$ 个可用的投影站位，其坐标分别为 $x_i$。如果两名虚拟偶像站位太近，全息投影的动作捕捉范围以及演出特效就会发生重叠，导致演出出现“穿模”事故。多多将一套站位方案的稳定程度定义为：任意两名虚拟偶像之间距离的最小值。请你帮多多计算一下，所有站位方案的稳定程度最大可以是多少？

### 输入描述

第一行为一个整数 $T$，表示共有 $T$ 个测试数据（$1 \leq T \leq 10$）。

每组测试数据：

- 第一行两个整数 $K, N$，其中 $K$ 是舞台的可用投影站位数，$N$ 表示参与演出的虚拟偶像总人数（$2 \leq N \leq K \leq 10^5$）。
- 第二行是 $K$ 个整数，表示投影站位序列，其中每个 $x_i$ 表示站位坐标（$1 \leq x_i \leq 10^9$）。

### 输出描述

每组数据输出一个结果，每个结果占一行。

### 补充说明

- 对于 $20\%$ 的数据有：$2 \leq K \leq 1000$，$1 \leq x_i \leq 10^6$。
- 对于 $100\%$ 的数据有：$2 \leq K \leq 10^5$，$1 \leq x_i \leq 10^9$。
- 对于同一组测试数据，所有 $x_i$ 两两不同。



### 思路

“最大化最小值” → 想二分；“是否可行” → 用贪心验证

### 实现

```python
class Solution:
    def max_stable(self, x, K, N):
        x.sort()
        left = 1
        right = x[-1] - x[0]
        ans = 0

        while left <= right:
            mid = (left + right) // 2
            cnt = 1
            last = x[0]
            for i in range(1, K):
                if x[i] - last >= mid: // 只要当前点和上一个选的点距离 ≥ mid，就选它
                    cnt += 1
                    last = x[i]
                    if cnt >= N: // 一旦够 N 个，就没必要继续扫描
                        break
            if cnt >= N:
                ans = mid
                left = mid + 1
            else:
                right = mid - 1
        return ans


def main():
    import sys
    input = sys.stdin.read().split()
    ptr = 0
    T = int(input[ptr])
    ptr += 1
    sol = Solution()
    for _ in range(T):
        K = int(input[ptr])
        ptr += 1
        N = int(input[ptr])
        ptr += 1
        x = list(map(int, input[ptr:ptr+K]))
        ptr += K
        print(sol.max_stable(x, K, N))


if __name__ == "__main__":
    main()
```



## 戴森环能源转运问题

### 题目描述

戴森环是一种环绕恒星建造、用于收集恒星能量的巨型人造天体结构。多多是负责转运能源的工作人员之一，他负责其中一条贯穿戴森环的直线检修带。本次任务他的飞船将停靠在坐标 $s$ 上，飞船可用于转运任务的总燃料为 $N$ 单位，若消耗超出限制，飞船将无法顺利返航。多多将沿着这条检修带回收沿途已经集满的能源仓，可以自行规划本次航线，既可以先朝坐标较小的方向推进，也可以先朝坐标较大的方向推进，飞船推进 $1$ 单位距离需要消耗 $1$ 单位燃料，任务途中可任意折返，但折返同样会消耗飞船燃料。能源仓散布在检修带上，不同能源仓由于工艺技术以及设备老化的原因，能够存储的上限能源量并不相同。第 $i$ 个已集满的能源仓位于坐标 $x_i$ 处，其中储满了 $c_i$ 单位能源，同一个能源仓在本次任务中至多只能完成一次转运，本次收集后则需要重新经历一段时间的积累。请你帮助多多计算本次任务最多能够转运多少单位的能源。

### 输入描述

第一行为一个整数 $T$，表示共有 $T$ 个测试数据（$1 \leq T \leq 10$）。

每组测试数据：

- 第一行三个整数 $N, M, s$，其中 $N$ 为本次转运任务的可用总燃料，$M$ 为本次任务已集满的能源仓总数，$s$ 为本次任务飞船停靠的初始坐标（$0 < s \leq N$）。
- 第二行包含 $M$ 个整数，表示已集满能源仓的坐标序列，其中每个 $x_i$ 表示坐标（$0 < x_i \leq 10^9$）。
- 第三行包含 $M$ 个整数，表示已集满能源仓的存储能量序列，其中每个 $c_i$ 表示 $x_i$ 处对应能源仓存储了多少单位的能源（$1 < c_i \leq 10000$）。

### 输出描述

每组数据输出一个结果，每个结果占一行。

### 补充说明

- 对于 $20\%$ 的数据：$0 < N < 5000$，$1 < M < 2000$，$0 < x_i, s \leq 10^6$。
- 对于 $100\%$ 的数据：$0 < N < 10^9$，$1 < M < 10^5$，$0 < x_i, s \leq 10^9$。

### 示例

输入

```
1
4 3 5
8 4 6
4 7 2
```

输出

```
9
```



### 思路

一条 **数轴**，起点在位置$s$，有 M 个点：坐标$x_i$，价值（能量）$c_i$，你的约束：

- 总移动距离 ≤ N（燃料限制）
- 可以来回走（允许折返）
- 每个点最多取一次

**最终路线一定是一个连续区间 [L, R]，包含 s**，也就是说：

- 你不会“跳着拿点”
- 一定是把某一段全部扫掉

为什么一定是区间？

假设你拿了：左边一个点 + 右边一个点，但中间没拿

那你实际上，已经走过中间了，不拿中间点是浪费。所以最优一定是：**从某个左边界 L 到某个右边界 R 的连续覆盖**。

问题变成：

> 选一个区间 [L, R]（包含 s），使：
>
> - 走完这个区间的“最小代价” ≤ N
> - 区间内的总价值最大

有两种走法：

方案1：先左再右

```
s → L → R
```

距离：$(s - L) + (R - L)$

方案2：先右再左

```
s → R → L
```

距离：$(R - s) + (R - L)$。

取最小值，总代价：$\text{cost} = (R - L) + \min(s - L,\; R - s)$。



**统一转换成“距离 s 的距离”**

- 左边：距离 = `s - x`
- 右边：距离 = `x - s`



### 实现

```python
import sys

class Solution:
    def solve_one(self, fuel, m, s, xs, cs):
        left = []
        right = []
        base = 0
        
        // 统一转换成“距离 s 的距离”
        for x, c in zip(xs, cs):
            // 左边：距离 = `s - x`
            if x < s:
                left.append((s - x, c))
            // 右边：距离 = `x - s`
            elif x > s:
                right.append((x - s, c))
            else:
                base += c

        left.sort()
        right.sort()

        ln = len(left)
        rn = len(right)

        # 左前缀：距离、能量
        l_dist = [0] * (ln + 1) // 拿左边前 i 个点，需要走多远
        l_sum = [0] * (ln + 1) // 这 i 个点的总能量
        for i in range(1, ln + 1):
            l_dist[i] = left[i-1][0]
            l_sum[i] = l_sum[i-1] + left[i-1][1]

        # 右前缀：距离、能量
        r_dist = [0] * (rn + 1)
        r_sum = [0] * (rn + 1)
        for i in range(1, rn + 1):
            r_dist[i] = right[i-1][0]
            r_sum[i] = r_sum[i-1] + right[i-1][1]

        ans = base

        # 情况1：只往左
        for i in range(ln + 1):
            if l_dist[i] <= fuel:
                ans = max(ans, base + l_sum[i])

        # 情况2：只往右
        for j in range(rn + 1):
            if r_dist[j] <= fuel:
                ans = max(ans, base + r_sum[j])

        # 情况3：左i → 回中点 → 右j
        j = rn
        for i in range(ln + 1):
            cost = 2 * l_dist[i]
            if cost > fuel:
                break
            rem = fuel - cost
            while j > 0 and r_dist[j] > rem:
                j -= 1
            ans = max(ans, base + l_sum[i] + r_sum[j])

        # 情况4：右j → 回中点 → 左i
        i = ln
        for j in range(rn + 1):
            cost = 2 * r_dist[j]
            if cost > fuel:
                break
            rem = fuel - cost
            while i > 0 and l_dist[i] > rem:
                i -= 1
            ans = max(ans, base + r_sum[j] + l_sum[i])

        return ans


def main():
    input = sys.stdin.readline
    t = int(input())
    sol = Solution()
    res = []
    for _ in range(t):
        fuel, m, s = map(int, input().split())
        xs = list(map(int, input().split()))
        cs = list(map(int, input().split()))
        res.append(str(sol.solve_one(fuel, m, s, xs, cs)))
    print('\n'.join(res))

if __name__ == "__main__":
    main()
```



## 魔法树能量水晶分配问题

### 题目描述

多多家里生长着一棵巨大的魔法树。这棵树由 $n$ 个魔法节点组成，节点之间通过 $n-1$ 条能量脉络相连（保证整体是一棵无向连通树）。

每个魔法节点都有一个“共鸣频率”，用一个整数数组 $\text{freq}$ 表示。为了维持魔法树的运转，你需要给每个节点分配能量水晶。

分配规则如下：

- 每个魔法节点至少需要被分配 $1$ 颗能量水晶。
- 对于任何通过能量脉络直接相连的两个节点，共鸣频率更高的节点，必须获得比另一节点严格更多的能量水晶。
- 如果直接相连的两个节点共鸣频率相同，它们之间的水晶数量没有任何约束。

请你计算并返回，为了维持魔法树的运转，最少需要准备多少颗能量水晶？

### 输入描述

第一行包含一个整数 $n$（$1 \leq n \leq 10^5$），表示魔法节点的数量。节点编号从 $0$ 到 $n-1$。

第二行包含 $n$ 个整数，第 $i$ 个整数表示 $\text{freq}[i]$（$1 \leq \text{freq}[i] \leq 10^9$）。

接下来的 $n-1$ 行，每行包含两个整数 $u$ 和 $v$，表示节点 $u$ 和节点 $v$ 之间有一条能量脉络直接相连。

### 输出描述

返回一个整数，表示最少需要的能量水晶总数。

### 示例

输入

```
4
1 3 2 4
0 1
1 2
2 3
```

输出

```
6
```

说明

该树为一条直线：$0(1) - 1(3) - 2(2) - 3(4)$

- 节点 $0$：$1$ 颗
- 节点 $2$：$1$ 颗
- 节点 $1$（连着 $0$ 和 $2$，频率最高）：需要比节点 $0$ 和 $2$ 都多，分配 $2$ 颗
- 节点 $3$（连着 $2$，频率比 $2$ 高）：分配 $2$ 颗

总计：$1 + 2 + 1 + 2 = 6$.



### 思路

- `u`：当前正在计算的节点
- `v`：u 的一个邻居

你有：

- 一棵树（n 个节点，n-1 条边）
- 每个节点有一个值：`freq[i]`

你要给每个节点分配一个整数 `a[i]`，满足：

**每个节点至少 1 个**：$a[i] \ge 1$

对每条边 (u, v)：如果：$freq[u] > freq[v]$，则必须：$a[u] > a[v]$

注意：

- 只对“直接相邻节点”有约束
- 相等频率 → **没有约束**

这题其实是在做：**给节点赋值，使得所有“大小关系”成立，并且总和最小**

$a[i] = 1 + \max(\text{所有比它小的邻居的值})$

因为每条边都要求“严格递增”，所以不可能形成闭环

### 实现

```python
import sys


class Solution:
    def solve(self, n, freq, edges):
        graph = [[] for _ in range(n)]
        // 构建无向图，graph[u] 存的是 u 的所有邻居
        for u, v in edges:
            graph[u].append(v)
            graph[v].append(u)

        order = list(range(n))
        order.sort(key=lambda x: freq[x])

        dp = [1] * n
        // 按频率从小到大处理
        for u in order:
            best = 1 // 当前节点 u 能取的最小合法值，初始为 1（最低要求）
            fu = freq[u]
            for v in graph[u]:
                if freq[v] < fu:
                    best = max(best, dp[v] + 1)
            dp[u] = best

        return sum(dp)


def main():
    input = sys.stdin.readline
    n = int(input().strip())
    freq = list(map(int, input().split()))
    edges = [tuple(map(int, input().split())) for _ in range(n - 1)]

    sol = Solution()
    print(sol.solve(n, freq, edges))


if __name__ == "__main__":
    main()
```
